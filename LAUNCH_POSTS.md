## LinkedIn

```text
I've launched RAGvidence, and I'm looking for engineers willing to try it and tell me what needs work.

When you change a RAG retrieval pipeline, did it actually retrieve the evidence your questions need?

RAGvidence is a fully free, open-source CLI for investigating that question on your own files:

• Run retrieval experiments on a file or folder.
• Compare retrieval techniques on the same data and questions.
• Inspect returned context and original source evidence.
• Export self-contained HTML reports, JSON, or Markdown.

BM25 needs no LLM or API key. Reviewed evidence lets you evaluate retrieval sufficiency; questions alone remain unscored. This evaluates retrieval, not generated-answer correctness.

If you're building a RAG project, try it on a small dataset. I'd value feedback on installation, confusing documentation, missing workflows, and whether the reports help you make a decision.

Website and demo: https://ragvidence.medo-id.com
Installation: https://ragvidence.medo-id.com/docs/installation
Code and issues: https://github.com/Medo-ID/ragvidence

Built by Medo-ID: https://medo-id.com
```

## Optional attachment and feedback

Attach the [34-second product walkthrough](https://ragvidence.medo-id.com/media/walkthrough.mp4)
or use the homepage link for its social preview. The walkthrough uses a synthetic
teaching example; its results are not a benchmark.

For bug reports, direct testers to the [CLI issue tracker](https://github.com/Medo-ID/ragvidence/issues).
Useful details: CLI version, operating system, command, expected result, actual
result, and a small non-sensitive reproduction. Do not ask testers to publish
private datasets, credentials, or whole workspaces.
